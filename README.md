# boxes
A discord bot to hold your hyperlinks in an easy to use database.

# commands

/newbox - Creates new named box
Options - [box-name] [entry-name] [hyperlink] 

/boxadd - Appends entry to box.
Options - [box-name] [entry-name] [hyperlink] 

/boxdel - Deletes box entry or list of entries
Options - [box-name] [entry-name || entry-index || entry-index-range]

/box - Returns list of box contents or specific entry
Options - [box-name] [entry-name || entry-index] 

/boxs [keyword] - Search boxes for entry or list of entries
